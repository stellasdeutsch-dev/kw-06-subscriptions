# Сайт №06 (шаблон по дизайну «Лендинг сервиса подписок»)

Две страницы на одних данных:
- `index.html`: гайд и в конце реклама Dias English и Alterna Timur;
- `lesson/index.html`: тот же гайд без рекламы, вместо неё короткая концовка.

## Как поменять текст
Все тексты, ссылки и порядок блоков лежат в `content.js`.
- `**слово**` делает выделение.
- Блоки идут в массиве `blocks` сверху вниз. Убрать блок: удалить его объект. Повторить: скопировать. Переставить: перенести.
- `only: "full"` показывает блок только на главной (реклама), `only: "lesson"` только на `/lesson/`.
- Ссылки покупки в `links` (у каждой кнопки рекламы `link: "dias"` или `link: "timur"`).
- Ответы для блока «Проверь себя» в `fields[].answers` (без учёта регистра).

Типы блоков: `hero`, `marquee`, `bento`, `check`, `rules`, `faq`, `band`, `author`, `task`, `solution`, `shots`, `levels`, `price`, `end`. Как устроен каждый, видно по готовым примерам в `content.js`.

## Как поменять цвета и шрифты
В начале `style.css`, блок `:root`. Убрать заглавные буквы в заголовках: `--head-case: none;`.
Шрифты лежат в `assets/fonts/`, подключены в `assets/fonts.css`.

## Как поменять картинки
Положить файл в `media/` (webp, до 1600 px, до ~250 КБ) и поменять путь в `content.js`.
Люди вырезаны скилом `cutout`, 3D-картинки сгенерированы в ElevenLabs.

```bash
cd gh && python3 -m http.server 8606
node ../qa/check.mjs --full
python3 -I ../qa/compare.py
```
Сборки нет: это статический HTML. Публикуется папка `gh/`.
